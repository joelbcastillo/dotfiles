INTEGRATION OVERVIEW
────────────────────────────────────────────────────────────────────────────────

WHAT IT DOES:
  • Global MCP profile manager for Claude Code
  • Switch between tool configurations: notion-only, docs-focus, project-focus, all-tools
  • Auto-detects projects with .mcp.json
  • Loads secrets from your 1Password setup
  • Works from any directory in a project

COMMANDS AVAILABLE:
  mcp-switch <profile>    # Switch profiles and load secrets
  mcp-profile show       # Show currently active tools
  mcp-profile list       # List available profiles
  mcp-profile status     # Check if secrets are loaded
  mcp-profile help       # Show help

HOW IT INTEGRATES:
  • Adds directly to: ~/.dotfiles/shells/oh-my-zsh/custom/functions.zsh
  • Hooks into your _secure_run pattern (for 1Password)
  • Uses your existing 1Password CLI setup
  • No changes to .zshrc needed
  • No new files or directories required
